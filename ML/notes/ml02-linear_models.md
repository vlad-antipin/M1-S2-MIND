# Perceptron

Initially algorithm had update rule for w that was more a heuristic (make w closer to misclassified points, don't touch if it works) it turned out to be equivalent to gradient descent with hinge loss function

Other losses - even some classified points contribute to cost (e.g. margin for SVM...)

NB: hinge loss function - infinity of minimums, since any scaling of w will work

Decision boundary is perpendicular to w since it corresponds to $w^Tx=0$ 

Note that when you increment w with a scaled version of a point x0 , w turns a bit in the direction of x0 and decision boundary turns accordingly (to make x0 closer to good classification)

Imagine two clusters, if SVM finds a line "in the middle", perceptron will find an "oblique" one kissing clusters and stops when all points are well classified

What if not linearly separable? Solutions:  add new dimensions (kernels...) or use ANN 

NB: ANN can be considered as adding new dimensions, but the difference is that they learn themselves how, whereas kernel methods are done ""a la main"
